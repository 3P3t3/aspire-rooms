# Aspire Health — the rooms

A single self-contained page: the walkthrough at
[aspirehealth.pro](https://aspirehealth.pro), built as rooms you move
through. One HTML file, no build step, no dependencies.

Published with GitHub Pages from this repository.

The working project — the catalogue, the build scripts and the
verification harness — lives in a separate private repository. This one
holds only the published page.

Product photographs are hotlinked from Amway and are Amway's. The personal
photographs are Peter Herschelman's own and already appear on
aspirehealth.pro.
